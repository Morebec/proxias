# Proxias

Deterministic intent interception for AI agents.

Proxias sits in front of an LLM. It classifies what a message asks for, runs a compiled, deterministic workflow when it recognizes one, and only falls back to the LLM when nothing matches: no multi-turn tool loop for what code can do reliably, quickly and cheaply.

> Work in progress: the first implementation is under review.
